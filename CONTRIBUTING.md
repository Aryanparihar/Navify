# Contributing to Navify

Thanks for your interest in improving Navify! This project is a Flutter UI prototype, so clarity, consistency, and visual polish matter.

## Ways to Contribute

- Report bugs or UI issues
- Suggest UX improvements
- Improve docs and setup instructions
- Add missing screens or components

## Development Setup

```bash
flutter pub get
flutter analyze
flutter test
```

## Pull Request Guidelines

- Keep changes focused and descriptive.
- Match existing formatting and UI styles.
- Update documentation when behavior or screens change.
- Confirm `flutter analyze` and `flutter test` pass.

## Reporting Issues

Please include:

- Device/OS details
- Steps to reproduce
- Screenshots or screen recordings
- Expected vs actual behavior

Thank you for helping improve Navify.
